# Dating App

Веб-застосунок для знайомств з розподілом анкети на Відкриту та Закриту інформацію
і розрахунком сумісності за матрицею долі.

Стек: Java 21, Spring Boot 3, Spring Security, Spring Data JPA, PostgreSQL, Thymeleaf.

Проєкт у розробці. Повний опис з'явиться після злиття основних модулів.
